# 環遊世界找分數

這是一個給國小二年級使用的單位分數對戰網頁。

學生觀察世界各國國旗，判斷主要色塊是否能平均分成 `1/2`、`1/3`、`1/4`，或選擇「沒有平分」。兩位玩家搶答，答對加分、答錯扣分，先到 10 分結束本局。

遊戲結束後，網頁會整理本局出現過的國旗、正確答案與單位分數示意，方便老師進行課後討論與概念澄清。

## 課堂使用重點

- 適合國小二年級「單位分數」概念練習。
- 可搭配投影、互動白板或學生平板進行。
- 建議老師在整理頁引導學生說明：「整體被平均分成幾份？其中一份是幾分之一？」
- 有徽章、星星或特殊圖案的國旗，可延伸討論「主要色塊」與「完全一樣大」的差異。
